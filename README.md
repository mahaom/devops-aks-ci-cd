# devops-aks-ci-cd

## DevOps AKS CI/CD Project

This project demonstrates an end to end DevOps pipeline using:
- GitHub Actions for CI/CD
- Docker for containerization
- Terraform for infrastructure as code
- Azure Kubernetes Service (AKS) for deployment

The project follows real world DevOps practices including automation, security, and monitoring.
